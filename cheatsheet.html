fzf fuzzy finder
Basic usage
fzfInteractive file picker from stdin
fzf --multiMulti-select with Tab / Shift-Tab
fzf --preview 'cat {}'Show file preview pane
fzf --preview-window=right:60%Preview pane on right at 60%
fzf --height 40%Use only 40% of terminal height
fzf --reverseInput at top, list below
fzf --exactExact-match mode (no fuzzy)
fzf -q "query"Start with initial query
fzf --filter "txt"Non-interactive filter mode
fzf --select-1Auto-select when only 1 match
fzf --exit-0Exit immediately if no match
Key bindings (interactive)
Ctrl-J / Ctrl-KMove down / up
Tab / Shift-TabToggle selection (--multi)
Ctrl-ASelect all (--multi)
EnterConfirm selection
Ctrl-C / EscCancel
Ctrl-/Toggle preview
Ctrl-RShell history (built-in binding)
Alt-Ccd into selected dir (built-in)
Search syntax
foo barAND match (both terms)
foo | barOR match
!fooNegate — exclude lines with "foo"
^fooPrefix match
foo$Suffix match
'fooExact match for "foo"
Shell integration snippets
vim $(fzf)Open picked file in vim
cd $(fd -t d | fzf)Jump to a directory
git log --oneline | fzfPick a commit interactively
kill -9 $(ps aux | fzf | awk '{print $2}')Kill a process
fzf --bind 'ctrl-y:execute(echo {} | pbcopy)'Copy selection to clipboard
export FZF_DEFAULT_COMMAND='fd --type f'Use fd as fzf's source
export FZF_DEFAULT_OPTS='--height 40% --reverse'Persist default options
Enable shell integration: eval "$(fzf --zsh)" (or --bash / --fish). Provides Ctrl-R history, Alt-C directory, and Ctrl-T file widget.
fd find alternative
Basic usage
fd patternSearch current dir recursively
fd pattern /pathSearch from given path
fd -e rsBy extension (.rs)
fd -t fFiles only
fd -t dDirectories only
fd -t lSymlinks only
fd -HInclude hidden files
fd -INo .gitignore — show all
fd -uUnrestricted (hidden + ignored)
fd -d 2Max depth 2
fd -s patternCase-sensitive search
fd -i patternCase-insensitive
Actions & filters
fd -x cmdExecute cmd for each result
fd -X cmdExecute cmd with all results
fd --size +1MFiles larger than 1 MB
fd --changed-within 1dModified in last 1 day
fd --changed-before 1wModified before 1 week ago
fd -oOwner info in output
fd -lLong listing (like ls -l)
fd --exclude dirExclude directory from results
bat cat with wings
Basic usage
bat file.rsDisplay file with syntax highlighting
bat -n fileShow line numbers only
bat -A fileShow non-printable chars
bat -p filePlain output (no decorations)
bat --pager=neverDisable pager, print directly
bat -r 10:20 fileShow lines 10–20 only
bat -H 42 fileHighlight line 42
bat --diff fileShow only changed lines (git diff)
Language & theme
bat -l json fileForce JSON syntax highlighting
bat --list-languagesAll supported languages
bat --theme=TwoDark fileUse a specific theme
bat --list-themesAll available themes
bat --theme='Monokai Extended'Theme with spaces
Set BAT_THEME or BAT_PAGER env vars for persistent config. Use bat cache --build after adding custom themes/syntaxes.
git-delta delta — diff pager
~/.gitconfig integration
[core] pager = deltaUse delta as git pager
[interactive] diffFilter = delta --color-onlyFor git add -p
[delta] navigate = truen/N to jump between hunks
[delta] side-by-side = trueSide-by-side diff view
[delta] line-numbers = trueShow line numbers
[delta] syntax-theme = DraculaSet syntax highlight theme
[delta] hyperlinks = trueClickable file links in terminal
CLI flags (override config)
delta --side-by-sideSide-by-side for this invocation
delta --lightLight terminal theme
delta --darkDark terminal theme
delta --diff-highlightdiff-highlight style (simpler)
delta --word-diff-regex=\w+Highlight word-level changes
delta --paging=neverDisable pager
git diff HEAD | deltaPipe any diff to delta
Navigation (interactive)
n / NNext / previous file (navigate=true)
qQuit pager
ag the_silver_searcher
Basic search
ag patternSearch current dir recursively
ag pattern /pathSearch from given path
ag -i patternCase-insensitive
ag -v patternInvert — lines NOT matching
ag -w patternWhole word match
ag -Q patternLiteral string (no regex)
ag -s patternCase-sensitive (default)
ag pattern -G '\.c$'Restrict to .c files (regex)
Output control
ag -l patternFiles with matches only
ag -L patternFiles without matches
ag -c patternCount matches per file
ag --nofilenameOmit filenames
ag -n patternLine numbers (on by default)
ag -A 3 pattern3 lines after each match
ag -B 3 pattern3 lines before each match
ag -C 3 pattern3 lines context (before+after)
ag --columnShow column numbers
File filters
ag -u patternSearch all files (ignore .gitignore)
ag --hidden patternInclude hidden files
ag --ignore "*.min.js"Exclude glob pattern
ag --python patternSearch Python files only
ag --list-file-typesAll supported --type flags
rg ripgrep — fast search
Basic search
rg patternSearch current dir recursively
rg pattern /pathSearch from given path
rg -i patternCase-insensitive
rg -s patternCase-sensitive (force)
rg -w patternWhole word match
rg -v patternInvert match
rg -F patternFixed string (no regex)
rg -e pat1 -e pat2Multiple patterns (OR)
rg -f patterns.txtPatterns from file
rg -U patternMultiline mode
rg -P patternPCRE2 regex engine
Output & context
rg -l patternFiles with matches only
rg -L patternFiles without matches
rg -c patternCount matches per file
rg -n patternShow line numbers (default)
rg -N patternSuppress line numbers
rg --column patternShow column of match
rg -A 3 pattern3 lines after match
rg -B 3 pattern3 lines before match
rg -C 3 pattern3 lines context
rg -o patternPrint only matching part
rg --no-headingOne result per line (grep-style)
File & type filters
rg -t py patternPython files only
rg -T py patternExclude Python files
rg --type-listAll supported types
rg -g '*.rs' patternGlob include pattern
rg -g '!*.min.js'Glob exclude pattern
rg -u patternIgnore .gitignore (add more -u to also show hidden)
rg --hidden patternInclude hidden files
rg --no-ignore patternDisable all ignore rules
rg -d 3 patternMax directory depth 3
rg --max-filesize 1MSkip files larger than 1 MB
Replace & advanced
rg -r 'new' patternReplace match in output (not in-place)
rg --json patternJSON output (for tooling)
rg -0 pattern | xargs -0NUL-delimited for safe piping
rg --stats patternPrint match statistics
rg -m 5 patternMax 5 matches per file
rg --sort pathSort results by path
rg pattern -. Search dotfiles in current dir
rg honours .gitignore, .ignore, and .rgignore. Create ~/.rgrc or set RIPGREP_CONFIG_PATH for permanent options.
